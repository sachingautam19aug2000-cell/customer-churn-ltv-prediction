# Customer Churn & LTV Analysis

## Project Overview

This project analyzes customer churn and customer lifetime value using Python, SQL and Power BI.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SQL
- Power BI

## Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. Feature Engineering
4. Churn Prediction
5. LTV Analysis
6. Power BI Dashboard

## Key Analysis

- Customer churn rate
- Churn by contract
- Churn by internet service
- Monthly charges analysis
- Customer Lifetime Value
- Churn prediction
- Model feature insights

## Dashboard

Power BI dashboard provides an interactive view of customer churn, revenue and customer segments.
